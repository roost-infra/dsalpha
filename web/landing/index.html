08 / 常见问题

你可能想先知道的。

如果这里没有答案，直接进工作台问它。

这和 ChatGPT / Claude 有什么区别？

聊天模型回答完就结束了。这里是一个带工具、文件系统和工作区的 Agent：它会取数、写代码、跑计算、生成报告，并把过程和结果留在 workspace 里，可以复跑、复核、继续改。

多个 Bot 会无限聊下去吗？

不会。消息链有深度、条数和时间预算；群聊按顺序发言，主持人控制节奏。Bot 之间的 Exchange 也有上限，预算用完后会要求回答当前请求，而不是继续转发。

定时任务会每次新开一个会话吗？

不会。选择目标 Bot 后，任务默认续用它已有的主会话；每 5 分钟唤醒盯盘手、盘前生成简报，都是往同一个会话里追加，上下文连续。

报告里的数字能核验吗？

能。Agent 的取数脚本、结果文件、图表和引用都留在工作区；HTML / Markdown 报告可以直接打开，也可以回到脚本重新跑一遍。

可以部署在自己的服务器上吗？

可以。核心 Agent 支持自托管，模型与数据密钥由你配置；适合需要把数据留在自己网络边界内的团队。
